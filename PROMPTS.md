# 🧠 AI Interview Agent — Project Notes

## 📌 Overview
The AI Interview Agent is a web-based system designed to:
- Conduct automated interviews
- Ask dynamic questions
- Evaluate candidate responses
- Provide feedback and scoring

---

## 🏗️ Tech Stack
- Backend: FastAPI (Python)
- Frontend: HTML / CSS / JS (or React if extended)
- AI Model: OpenAI API
- Server: Uvicorn
